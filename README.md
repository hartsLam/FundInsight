# FundInsight

**将基金持仓、净值走势、市场资讯与 AI 问答集中展示的轻量研究面板。**

项目采用 Node.js 服务端与原生网页前端，可在本地运行或部署到 VPS。默认观察宏利成长混合（162201），支持在前台添加和切换基金。

> 本项目为脱敏源码分享版，不包含原部署的 API Key、密码、运行数据或缓存。运行前需自行设置访问密码，AI 功能需配置自己的服务商凭据。所有分析仅用于信息整理和研究辅助，不构成投资建议。

## 主要功能

| 模块 | 功能 |
| --- | --- |
| 基金概览 | 展示公布净值、估算净值、估值涨跌及对应日期。 |
| 持仓分析 | 重仓股明细、行业分布、季度调仓变化和静态持仓贡献。 |
| 净值走势 | 盘中估值与历史净值切换，支持选择历史时间范围。 |
| 短线状态 | 根据有效行情提供规则参考，并解释判断依据。 |
| 新闻解读 | 围绕持仓和行业检索资讯，由 AI 解读并附来源。 |
| 智能问答 | 按需读取基金数据、技术指标和联网资料，支持流式回答与追问。 |
| 基金管理 | 前台添加、移除和切换基金，记忆浏览器上次选中的基金。 |
| 界面设置 | 四套主题、毛玻璃强度、可拖动缩放的聊天窗口及移动端适配。 |
| 管理后台 | 配置优先行情来源、AI 地址、模型和搜索渠道。 |

## 实现流程

```text
用户访问页面或提问
    → 服务端验证权限
    → 读取有效缓存，或请求基金、行情和资讯来源
    → 解析数据，校验日期与缺失值，计算技术指标
    → 直接展示数据，或按需调用 AI 分析
    → 返回结果、来源与必要的限制说明
```

技术指标由程序计算，AI 负责结合证据解释。历史净值指标使用截至选定日期的完整序列计算，不以图表抽样点代替原始数据。

新闻检索与解读分别使用 **15 分钟缓存**，同一任务的并发请求合并。基金问答按需调用模型并复用可用资料，已完成的个性化回答不作为公共回答缓存。行情、历史净值和行业分类采用各自的缓存策略。

## 快速启动

### 安装依赖

项目声明的运行要求为 **Node.js 18 或以上**，需要能够访问外部数据接口。无需安装数据库或单独构建前端。

在项目目录执行：

```sh
npm ci
```

### 设置密码并运行

分享版必须设置 `ACCESS_PASSWORD`，否则拒绝启动。前台访问密码与后台管理员密码相互独立。

**Windows PowerShell：**

```powershell
$password = Read-Host '设置前台访问密码' -AsSecureString
$env:ACCESS_PASSWORD = [System.Net.NetworkCredential]::new('', $password).Password
$env:ACCESS_SECRET = node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
npm start
```

**Linux Bash：**

```bash
read -rsp '设置前台访问密码: ' ACCESS_PASSWORD
printf '\n'
export ACCESS_PASSWORD
export ACCESS_SECRET="$(node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))")"
npm start
```

以上变量在当前终端会话中生效。重新生成 `ACCESS_SECRET` 会使原有前台登录会话失效；长期部署应通过进程管理器安全保存固定的随机值。

启动后访问：

- 前台：<http://localhost:3210>
- 管理后台：<http://localhost:3210/admin>

未设置 `ADMIN_PASSWORD` 时，首次启动生成随机管理员密码，保存到 `data/admin-password.txt`。仅在服务器本地查看和保管，不要公开该文件。

## AI 与数据源配置

进入 `/admin`，使用独立管理员密码登录后：

1. 选择东方财富或腾讯作为优先行情来源，实际回退能力取决于对应接口。
2. 填写兼容 Chat Completions 的公网 HTTPS 地址、模型名和自己的 API Key，再启用 AI。
3. 选择 Tavily、火山引擎、腾讯云、阿里云百炼，或不需要搜索 Key 的财经资讯筛选模式。
4. 保存后在前台提问或获取新闻解读，检查返回内容与来源。

各平台凭据不能混用。仅使用财经资讯筛选模式时，不具备通用联网搜索能力。模型与搜索服务可能分别计费，缓存可以减少重复请求，但不能保证零费用。

未启用 AI 时，基础基金与行情功能仍可使用，但依赖外部来源可用性。适配细节见 [AI 后台与部署说明](AI-DEPLOY.md)。

## VPS 部署

上传源码后执行 `npm ci`，以 `npm start` 或 `node server.js` 启动。可由宝塔 Node 项目或其他进程管理器托管，并通过 Nginx 反向代理到本机 `3210` 端口。

| 环境变量 | 说明 |
| --- | --- |
| `ACCESS_PASSWORD` | 必填，前台访问密码。 |
| `ADMIN_PASSWORD` | 独立管理员密码；未设置时生成随机密码并保存。 |
| `ACCESS_SECRET` | 会话签名密钥，建议配置持久的高强度随机串；未设置时每次启动随机生成。 |
| `PORT` | 服务端口，默认 `3210`。 |
| `FUND_CODE` | 初始基金代码，默认 `162201`；已有基金列表由运行数据管理。 |
| `REFRESH_MINUTES` | 行情刷新间隔，默认 `5` 分钟。 |
| `AUTH_TIMEZONE` | 会话日期使用的时区，默认 `Asia/Shanghai`。 |
| `PUBLIC_ORIGIN` | 公网站点来源，例如 `https://example.com`，须与浏览器一致，不带路径。 |
| `COOKIE_SECURE` | HTTPS 部署设为 `1`；本地 HTTP 测试不设置。 |

**程序不会自动读取 `.env` 文件。** 请将变量注入实际启动 Node 的进程环境，修改后重启进程。

使用单 Node 进程部署；当前并发合并机制不支持跨进程或跨 VPS 共享锁。`data/` 需要服务进程的写入权限，但不可映射为公开静态目录。更新现有部署前备份运行数据，不要用分享版覆盖原有密钥配置。

## 数据来源与使用边界

- 基金披露和历史净值：天天基金、东方财富公开数据。
- 盘中估值：新浪财经等已适配来源，页面标注实际来源和日期。
- 股票与指数行情：东方财富、腾讯、新浪等已适配接口，按有效性及接口能力补充。
- 行业分类：东方财富公司资料的 EM2016 行业层级，不等同于申万分类。
- 资讯和外部证据：财经资讯接口及后台选定的搜索服务。

披露持仓不是实时组合，静态持仓贡献不等于基金实际涨跌，单位净值变化也不等于复权收益。分时日期无法核实时，不应将曲线作为今日走势。

不同基金的数据覆盖不同，不保证债券、货币或 QDII 基金具备全部股票分析功能。外部接口可能限流、变更或失效；缺失数据应显示不可用或降级提示。AI 仍可能出错，重要结论应核对原始来源。

## 测试与排查

```sh
npm run check
npm test
```

脱敏打包时的 96 项自动化测试全部通过。测试包含模拟接口与异常场景，不代表真实来源始终可用，也不代表 AI 结论全部准确。

| 情况 | 检查方向 |
| --- | --- |
| 启动提示设置访问密码 | 将 `ACCESS_PASSWORD` 注入实际启动 Node 的进程。 |
| 请求来源无效 | 检查 `PUBLIC_ORIGIN` 的协议、域名和端口是否与浏览器一致。 |
| AI 尚未配置或调用失败 | 检查后台开关、地址、模型、渠道凭据、额度与 VPS 出站网络。 |
| 行情缺失或短线数据不足 | 检查来源、日期与错误提示；切换优先来源不保证修复上游故障。 |
| 分时日期待核实 | 来源缺少充分日期证据，不能强行把旧曲线标为当天。 |
